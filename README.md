# Task List

A simple Laravel task manager (CRUD) application.

Requirements

- PHP 8+, Composer, and a database (SQLite/MySQL/Postgres).

Quick start

1. Install dependencies: `composer install`
2. Copy env: `cp .env.example .env` and set DB settings
3. Generate key: `php artisan key:generate`
4. Run migrations: `php artisan migrate`
5. Serve: `php artisan serve`

Routes

- Main list: `/tasks`
